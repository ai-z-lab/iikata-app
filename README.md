# その言い方、損してない？変換App

## アプリ概要
「その言い方、損してない？変換App」は、きつく聞こえやすい言い方を、相手に伝わりやすい表現へ変換する静的Webアプリです。

## 公開URL

> ※実際の公開URLに合わせて置き換えてください。

## 使い方
1. 「変換したい言葉」に文章を入力します。
2. もしくは、用意された例文ボタンを選んで入力をセットします。
3. 「変換する」を押すと、判定カテゴリと複数の言い換え候補が表示されます。
4. 必要に応じてコピーして利用します。

## 現在のステータス
- 現在は**試作版**です。
- 職場で使いがちな言い方を中心に変換します。

## 入力について
- 例文を選ぶか、自由入力で利用できます。
- 方言やくだけた表現は、標準語に近い形で変換される場合があります。
